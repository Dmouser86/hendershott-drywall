# Hendershott Drywall & Repair LLC — Official Website (`hendershottdrywall.com`)

Professional website for **Hendershott Drywall & Repair LLC**, owned and operated by **Kevin Hendershott** in Scott City, MO, serving all of Southeast Missouri.

## Repository Structure

- `index.html` — Homepage with Hero, Quick Service Request Form, Core Specialties, Interactive Drywall Sheet & Scope Estimator, and Featured Projects
- `services.html` — Full breakdown of Drywall Hanging, Taping & Level 5 Finishing, Patching, Ceiling Texture Matching, Custom Archways/Coffered Ceilings, 24/7 Emergency Water-Damage Repair, and Interactive Gypsum Finish Level Guide
- `about.html` — Owner-operated story, Scott City & Southeast Missouri service info, and interactive FAQ accordion
- `gallery.html` — Filterable 6-project photo portfolio with interactive full-screen Lightbox inspection
- `contact.html` — Online Estimate & 24/7 Emergency Dispatch Form with SMS & Email quick-send integration
- `styles.css` — Responsive dark/industrial red & cream stylesheet
- `script.js` — Interactive navigation, drywall material calculator, gallery filter, lightbox modal, and form handler
- `assets/` — Brand logo (`assets/logo.png`) and project photos (`assets/photos/`)

## Deploying to GitHub Pages

1. Commit all files in this directory to the root of your GitHub repository.
2. In your GitHub repository, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** and choose `main` / `/ (root)`.
4. (Optional) Enter `hendershottdrywall.com` under **Custom domain** and enable **Enforce HTTPS**.
